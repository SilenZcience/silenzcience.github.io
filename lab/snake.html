Build note 001

Input queues beat input events.

Fast direction changes arrive between ticks, so keystrokes are queued rather than applied instantly. The classic bug where a snake reverses into itself inside one frame stays impossible by construction.

Build note 002

Need for speed.

The game speeds up as you eat more food, making it increasingly challenging to maintain control. Go turbo!
