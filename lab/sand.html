Build note 001

How it works.

On the 2D grid each cell is either empty, sand, or stone. Every frame, sand grains update bottom-up: a grain drops if the cell below is free, or slides diagonally if a side cell is open. No forces or collisions, just one conditional chain per cell that lets sand pile, flow, and avalanche.

Build note 002

Alternating sweep.

Scanning cells strictly left-to-right would let grains lean towards one direction, building a subtle bias into every sandpile. So the simulation flips sweep direction every frame creating a perfectly balanced system; As all things should be.
