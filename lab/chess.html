Build note 001

Pruning, not brute force.

The engine uses negamax (a minimax variant): from any side's point of view, its own best move is the negation of the opponent's best reply, so one search routine serves both players. A full search tree over chess explodes combinatorially so the engine uses αβ-pruning to abandon any branch that provably cannot beat a move it has already found. This cuts most of the searchtree (and searchtime) while returning exactly the same answer. Captures are examined first so cutoffs arrive early.

Build note 002

Forsyth-Edwards Notation.

FEN is the standard notation for a whole chess position. First it describes the board, ranks 8 to 1, joined by slashes, with letters for pieces (uppercase white, lowercase black) and digits for empty squares. Next one letter indicating whose turn it is (w or b). Then castling rights as K, Q, k, q for whichever of king/queenside is still allowed ('–' if none), followed by the en-passant target square ('–' if none). Lastly the halfmove clock (plays since the last capture or pawn move) and the fullmove clock. One short line holds the complete game state.
