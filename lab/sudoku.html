Build note 001

Solving a puzzle.

A new puzzle starts empty. Each cell tries values 1–9, but only accepts one that violates no row, column, or 3×3 box rule. When a cell runs out of options it backtracks to the previous choice and tries a different path. That simple bruteforce pass alone fills an entire valid grid in no time.

Build note 002

Generating a puzzle.

A playable board is carved out of the solved grid by removing numbers one by one given that the puzzle still has only one solution without that number. The difficulty setting simply adjusts how many numbers are left. 'Easy' keeps 45, 'Medium' keeps 35 and 'Hard' keeps 28, whereas 'Expert' tries to leave less than 24.
